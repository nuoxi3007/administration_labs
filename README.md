# Лабораторные работы по администрированию PostgreSQL

Учебные работы по управлению доступом, транзакциям, блокировкам, аудиту и обслуживанию баз данных PostgreSQL.

## Содержание

### 1. `Lab_Roles1.sql`  Управление ролями и правами доступа
Создание ролей пользователей, настройка привилегий с помощью `GRANT` и `REVOKE`, изучение наследования ролей и проверка доступа к объектам базы данных.

### 2. `Laba2.sql` MVCC и управление транзакциями
Изучение механизма MVCC, уровней изоляции транзакций и особенностей параллельного доступа к данным.

### 3. `Lab_3.sql` Блокировки и взаимоблокировки
Работа с блокировками PostgreSQL, анализ активных сессий через `pg_stat_activity` и `pg_locks`, изучение причин возникновения deadlock.

### 4. `functions.sql`  Функции и процедуры
Работа с функциями и процедурами на PL/pgSQL, изучение режимов безопасности `SECURITY INVOKER` и `SECURITY DEFINER`, анализ выполнения SQL-запросов.

### 5. `trigger.sql`  Триггеры PostgreSQL
Создание и проверка триггеров для автоматического выполнения действий при изменении данных.

### 6. `audit.sql`  Аудит изменений данных
Настройка аудита операций с данными с помощью триггеров и сохранение информации об изменениях в таблице аудита.

### 7. `monitoring.sql` Мониторинг PostgreSQL
Изучение инструментов мониторинга состояния базы данных и анализа статистики выполнения запросов.

### 8. `restore8.sql`  Резервное копирование и восстановление
Работа с операциями резервного копирования и восстановления базы данных PostgreSQL.

## Используемые технологии

- PostgreSQL
- SQL
- PL/pgSQL
- Системные представления и каталоги PostgreSQL
